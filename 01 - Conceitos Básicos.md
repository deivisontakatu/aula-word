# 📝 Word — Conceitos Básicos

## 📌 Introdução

O Word é um editor de texto utilizado para criação, edição e formatação de documentos.

---

## 🧠 Editor de Texto

Permite:

* Criar documentos
* Editar textos
* Formatar conteúdo

---

## 📄 Documento

Arquivo criado no Word.

Extensão:
.docx

---

## 🧱 Interface

Principais elementos:

* Faixa de opções (Ribbon)
* Barra de ferramentas
* Área de edição

---

## 📑 Faixa de Opções

Organizada em guias:

* Página Inicial
* Inserir
* Layout
* Revisão

---

## ✍️ Área de Digitação

Local onde o texto é inserido.

---

## 🔄 Cursor

Indica onde o texto será digitado.

---

## 💾 Salvamento

Ctrl + S → salvar documento

---

## ⚠️ Pegadinhas

* Documento ≠ arquivo aberto
* Cursor ≠ mouse
* Word ≠ sistema operacional

---

## 🧠 Boas Práticas

* Salvar frequentemente
* Nomear arquivos corretamente
* Revisar conteúdo

---

## 📌 Conclusão

O domínio da interface facilita a produção de documentos organizados.
